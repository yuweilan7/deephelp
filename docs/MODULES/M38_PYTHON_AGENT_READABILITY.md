## 覆盖范围

审阅三个包的自有Python实现，重点是Agent/会话主线、模型网关、实体与意图、检索与归属、SOP/MCP、记忆、审批恢复、评测发布，以及支撑这些能力的配置/装配/异步/持久化代码。学习实验与必要测试fixture说明其教学或验证目的；有实际教学需要的infra Python入口也纳入。只给复杂测试的场景、故障和独立断言补解释，不逐条翻译assert。

不为Vue/TypeScript/CSS、数据JSON/JSONL、锁文件、第三方或生成文件补注释，不为这些文件引入新的注释格式。必要数据结构含义在Python消费者或现有课程解释；不改变数据格式、Prompt、业务规则或模型策略来凑教学内容。代码标识符与公开接口保持原语义，不机械翻译名称和协议字符串。

## 注释怎样才算讲清楚

| 位置 | 应解释的内容 | 深度边界 |
|---|---|---|
| 有实际逻辑的模块/类 | 负责什么、谁调用、主要输入输出/状态、从哪里开始读 | 简单导出/CLI转调只需一句职责与实现去向；不要求所有文件同一模板 |
| 重要函数/入口 | 参数在业务中表示什么、返回什么、改变什么、主要错误或副作用 | 纯取值、赋值、显然的转换不逐行复述 |
| 意图/Agent分支 | 当前判定的依据，模型建议与代码守卫的分工，为什么不能走另一条路 | 不编造隐藏推理；不把注释中的预期写成模型已保证 |
| await/任务/锁/事务 | 等什么、谁拥有、保护哪个不变量、什么时候提交/取消/释放 | 相同简单模式复用已有解释，关键拥有者/时序变化必须解释 |
| 高级Python写法 | 本行用途、展开后的含义、为什么使用、普通替代与适用边界 | Java类比准确；Task不是线程，await不是阻塞Future.get |
| 异常/恢复/预算/证据 | 失败在哪层收口，哪些事实已提交，哪些未知，为什么不能重放 | 保留原幂等/UNKNOWN/累计预算/不可变版本边界 |

中文说明用完整、短而连贯的句子，先业务含义再必要术语。复杂段落可以有多行说明和小例子；长篇原理继续放现有docs/learning，源码解释眼前的参数、分支与时序。不能只把英文术语换成中文名词，不能只增加一行模块标题，也不能用注释比例或统一行数作为通过标准。

示例标准：对于终态保存，说明“当前请求创建保存任务；外层收到取消后仍等待这次短保存完成，再把取消交还调用者；这段保护不允许模型或工具继续执行”，并核对实现确实如此。简单的列表长度读取无须写“获取列表长度”。

## 两个顺序特性

1. **Python/Agent主链中文导读与局部可读性修正。** 沿输入→实体/归属→600意图→SOP/工具→事实回复→终态/诊断→审批恢复逐段走查；补函数契约和关键分支注释。难读写法只在等价且更清楚时改写，同步现有课程的源码入口。
2. **支撑路径讲解、职责收口与覆盖核对。** 继续模型/检索/PG/Redis/MCP适配、装配资源、学习实验、评测/发布/探针等Python路径。核对混杂职责与必要兼容入口，对实际问题做小范围整理，完成全范围审阅和例外说明。

初步候选包括Redis从Milvus模块导入通用配置、Milvus适配器内的SSH容量探针、工作台evaluation内的路由与长任务执行、会话外部函数绑定。它们是走查线索，不预先判定都必须拆分；以调用关系、可读性收益和行为证据作决定。不重新划分全项目架构，不追求文件统一短小，不因多个消费者使用同一入口就新建抽象层。

同名文件、重复导出或旧CLI转调不等于重复实现；核对动态装配、部署与保留安装消费者。确需合并或迁移时只保留一个实现，更新引用与针对性测试；与该整理直接相关的失效源码随特性清除，其余文件清理留M39。

## 可观察的验收

交付说明按现有子系统列出已审阅范围、关键改动和无需详细注释的理由，不创建永久注释计数看板。代表性走查必须覆盖主链、模型解析、检索/记忆、MCP、审批、取消/事务和评测发布；能从代码回答输入输出、调用者、状态/资源拥有者、失败处理及关键选择原因。全范围审阅不能只挑少数样板文件做完便宣称所有Python已处理；不宣称用户已经学会。

纯注释变更先比较AST/运行字符串与资源差异，再做适用语法/格式、导入及课程链接检查。docstring会改变AST文本，应只排除真正的文档字符串节点；如有程序读取`__doc__`须检查消费者。发现可执行表达式、常量、参数或控制流改变时按行为变更处理，不用“加注释”跳过验证。等价职责整理核对原断言和动态入口，按影响运行相关回归；不增加镜像实现式测试或全套模型调用。

默认验收为离线。源码注释改变包字节但不等于模型质量变化，不自动重复live或更新云安装。若明确交付新云安装，仍按现有精确内容发布/恢复规则执行，不能修改旧manifest；STATE区分本次源码与仍在运行的已验安装。模型/Prompt/解析/决策实际变化则先说明影响，再按ROADMAP选择必要真实样本。
