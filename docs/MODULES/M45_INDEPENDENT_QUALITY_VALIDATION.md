# M45｜独立盲测与可验证的质量改进闭环

**状态：** `IN_PROGRESS`；2026-10-06 F1独立AI冻结及F2真实dev配对已验，Hybrid/Dense各15/16、无逐例变化，F3审核修订/holdout继续；证据见[交接](../../handoffs/M45.md)。
**来源：** PDF文件页70–71的标准化评测、消融与审核反馈，以及页75–76的持续优化。PDF提到500条真实样本/15类场景等目标，不能写成本项目已有数据或既定成绩。
**基线：** M39；复用[M17](M17_EVALUATION.md)、[M18](M18_DATA_FLYWHEEL.md)、[M29](M29_LANGFUSE_ENGINEERING.md)、[M31](M31_RERANK_INTEGRATION.md)、[M35](M35_FRONTEND_FOUNDATION.md)。可直接评测当前引擎，不等待M40–M44/M46全部完成；新能力只在实际交付后进入对应实验。

## 解决什么缺口

现有规模/真实模型/持久协议与发布证据已经有效，但主要来自同作者合成数据；M29两Prompt版本内容等价，M31 test总体持平且有退化。接通评测平台、产生新版本或某条修复不能证明整体回答质量提升。

本M新增独立样本来源/盲审与可复现对照，把“为什么变好、哪里变差、是否值得发布”做成实际闭环。它是新的质量能力，不是替其他M补注释、补页面、扫全仓库。各feature自己的固定反例/受影响门禁仍在各自交付时完成。

## 三个顺序feature

### 1. 独立数据集与盲审流程

交付样本接收/脱敏、来源分级、独立标注/分歧复核、场景与多轮去重组、train/dev/锁定holdout以及版本化审核记录。按会话/近重复簇隔离，冻结测试集之后再做策略修改；标注者在定标签时不能看被测版本的答案来确认金标。

实际数据可以是获准使用的客户资料，或由不同作者独立编写并盲审的合成数据；两者分开报告，独立合成不冒称真实客户。样本数与覆盖按取得的数据列实值；缺少独立来源时标记`DATA_NOT_AVAILABLE`并保留接入/审核入口，不伪造500条真实样本或用同作者改写补齐。必要独立数据未到位时不报告整个M完成。

同步中文讲解泄漏/盲审/去重与split拥有者，在原评测页面展示真实来源/样本数/分歧/锁定状态；给小合成离线泄漏反例及预期拒绝结果。临时原始导入只按脱敏/恢复需要保留，不进入公开仓库，处理完的无引用副本当项删除。

### 2. 精确版本基线与配对对照

交付针对明确能力的baseline/candidate实际运行和逐例配对报告。分类用准确率/Precision/Recall/F1及混淆/拒识，检索用Hit/MRR及召回覆盖，回复/业务用证据一致、正确补槽、解决/人工边界与实际失败；解释不同指标的分母，不从HTTP200或终态标签推导“首问解决”。

每次只变一个有意义因素或明确多因素组合，比较同样本/工具事实与匹配资产；Dense/Hybrid/Rerank消融共享规定的候选/向量条件，模型随机性按预先确定的有限重复记录。报告改善/退化样本、调用/已知usage/延迟及小样本不确定性，不能只挑有利组。

先声明预算和必要真实范围，再执行，不自动启动所有模型×所有策略全排列。同步讲解统计/对照条件，在原评测工作台展现原样本、版本、结果来源、差异和未运行组；修复直接相关评测兼容问题，保留必要逐例证据而非永久重复导出。

### 3. 审核驱动的一轮改进与留出集复验

从dev/已审业务反馈选择一个明确问题，交付可追溯候选修订及原飞轮发布链；修订前确定主指标、最低改善/可接受退化和关键守卫，修订后在锁定holdout执行规定比较。开发者不据holdout逐条答案反复调参；用过的测试集如转入开发须另建独立留出集。

收益成立且守卫/门禁通过时才发布候选，实际安装/恢复按原精确绑定；无收益、样本不足或关键退化时保留baseline，记录拒绝候选及原因。负面结果可以证明评测/审核能力完成，不能被写成质量已提升；如果必要数据/真实比较未完成则仍未完成。

原工作台显示反馈→审核→修订→对照→采用/拒绝的具体证据链，教程给正确/错误读报告例子；当项清理无消费者候选/中间报告，旧manifest/有效失败与恢复证据保持。

## 可观察的验收

| 证明目标 | 最小必要证据 |
|---|---|
| 独立性 | 真实来源/作者/标注流程与样本实数，split/去重/盲审可追溯；真实与独立合成分开 |
| 对照有效 | 冻结样本、精确版本/配置/资产、逐例结果与分母；重复/条件差异披露，不能只展示聚合高分 |
| 改进闭环 | 一轮已审修订及holdout复验，采用或拒绝有预先标准与实际证据，原版可读/可恢复 |
| 平台/预算 | 原任务取消/INTERRUPTED/未知用量正确；平台故障不重新执行业务；大批量付费不超授权 |
| 学习与结果诚实 | 浏览/历史0模型；页面能解释指标、退化、数据来源、未验范围，无提升时保留原结论 |

适用[每个feature习惯](../../AGENTS.md#每个feature的编码与交付习惯)。针对性工程门禁和独立质量证据各自有效；本M完成不宣称达到企业泛化、PDF解决率或长期SLA，也不保证所有新策略优于基线。

## 完成与停止

独立数据、真实配对评测、审核修订/留出集复验三项均有必要证据并顺序Git交付才更新整个M完成及`handoffs/M45.md`。缺真实客户数据时可在披露的独立合成范围交付，不扩大结论；缺任何独立数据时保留未完成状态，不以自测冒充。停止于本次质量能力，不自动转向全项目重构或下一M。
