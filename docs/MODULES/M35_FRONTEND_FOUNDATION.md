## 技术与交付形态

选Vue 3 + TypeScript + Vite + Element Plus：用单文件组件/类型化API/成熟表格表单组织学习工作台。依据[Vue组件与渐进采用](https://vuejs.org/guide/introduction.html)、[Vite构建](https://vite.dev/guide/)、[Element Plus安装](https://element-plus.org/en-US/guide/installation.html)。版本/Node要求在实施时核对并精确锁定，当前规划不伪造已安装版本或兼容性。

源码仍只有modules/deephelp-app/frontend一份；增量使用一个前端package清单与对应锁文件，Python继续唯一uv.lock。开发允许Vite本机代理现有API，云运行由原应用同源提供构建静态文件，不新开Node常驻服务，不引入SSR、独立BFF或第二套业务API。依赖本地构建/打包，不运行时拉CDN。

## 两个顺序特性

1. **组件骨架及对话主线：** 交付导航、统一布局/视觉语言、类型化API客户端、可访问的组件、对话/历史/事实证据页面和免登录协商；保留原message/session/question/retry语义，完成新构建→wheel同源运行闭环。
2. **完整功能迁移：** 迁入业务维护、MCP、SOP/审批图、意图实体、检索、记忆、观测、评测飞轮；同教程的场景入口和状态说明接通；原能力逐条对照，删除旧巨型JS/HTML及重复样式/路由，完成正式个人安装与恢复。

第一项不能以“只做外壳”交付：至少一条完整请求/历史阅读链可运行。第二项必须保留现有四组学习/飞轮能力，不能为页面变好看丢掉有效功能。

## 页面和文件职责

frontend/src按app入口/路由、features业务页面、components通用展示、api/types协议、composables请求/分页状态、styles设计基础、content场景帮助归组。不按M编号建tab，不把所有API/组件/样例塞进utils.ts或一个全局store；仅跨页共享且有消费者的状态引入Pinia，路由按真实页面使用Vue Router。

首页先显示“从哪里开始”和当前模式/依赖状态；侧栏按学习任务组织：对话全过程、业务资料、识别与检索、多轮记忆、工具与工作流、观测诊断、评测与改进。机制介绍与细节通过逐层展开承载；M36再深化可解释的真实运行投影，M35先把入口、信息层次和全部原能力组织清楚。

所有页面提供中文标题、当前目标、所需数据/服务、操作步骤、预期观察、实际结果及相关教程链接。用正常/等待补充/等待审批/失败/取消/未运行/不可用/空数据区分状态；“请求成功”不能代表内容通过。空数据给下一步操作，依赖失败说明哪个组件/哪个动作受影响及恢复入口，不输出Python栈给初学者当说明。

列表有检索/分页/明确选中状态；对话、事实、历史、观测之间有稳定的当前session/run关系。保留键盘操作、焦点/状态可读性、足够对比度和窄屏重排。详情的原始JSON可展开，主页面先呈现业务含义。loading/错误/空白不能挤成同一种空卡片；不虚构仪表盘百分比/服务健康。

## 数据和异步界面约束

API types消费现有契约，不在前端实现实体提取、意图归属或SOP判断。请求切页/选中run变化时取消旧读取或校验序号，防止旧结果覆盖新选择；取消浏览器等待不表示服务器业务取消，未知发送结果保留原message_id供显式核对/重试。新提问才新message_id，补槽绑定原question/version。

查询与执行使用不同操作文案；页面浏览、刷新、教程、历史和观测均0模型。实际模型动作显示必要范围/当前预算并由用户明确执行；重任务继续复用唯一worker、累计预算、INTERRUPTED和有界尝试，不在mounted/watch中自动发模型请求。业务金额为十进制字符串，更新使用原CAS，不让组件乐观展示未确认的业务效果。

## 构建与验收

前端类型/组件/路由检查和必要行为测试覆盖请求竞争、错误/空态、消息重试、预算、任务取消和展示数字来源，避免只测试组件内部实现。实际浏览器检查主要页面、宽/窄布局及关键控件，迁移矩阵逐项对照原M22功能和API语义。

CI/打包验证app的sdist→wheel包含唯一已构建静态资源，无node_modules/开发缓存/临时dist副本；开发源码与安装包实际服务字节对应。Vite哈希资产、路由刷新、CSP和资源路径可用；运行完整指纹必须涵盖所有实际服务资产及构建manifest，不能因换后缀绕过发布校验。旧清单/旧页面资产不混入新安装。

主要是界面/组织变更，离线先验，实际浏览器用固定合成数据/原run验证；真实内容只为新安装或改变的行为选必要样本，完整正式发布按既有精确门禁，不再跑四组大规模消融。全部通过后同源交付个人云入口，保留旧安装/完整release恢复资料，全部特性交付后停止。
