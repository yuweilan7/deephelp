## 范围只有文件清理

清理已确认不再需要的受控/忽略文件、过程副本、失效源码、冗余测试和空目录。可以同步修正删除直接造成的链接、资源/安装引用与必要清理记录；不扩成文档重写、课程扩展、界面改造、架构重构、新部署/发布、数据库重置或新建练习数据管理功能。

主范围为当前仓库及本轮明确创建的临时文件。云端文件只在能够核对其确切来源、当前进程/配置/安装/发布/恢复消费者时处理明确多余副本；无法核实则保留具体对象并说明，不以“彻底清理”为由清空云运行根、数据卷或备份。单人学习/测试数据不改变受引用文件的用途判断。

## 两个顺序特性

1. **仓库受控文件清理。** 核对无效/重复源码、测试、模板、已完成PLAN和重复过程文档，实际删除确认无消费者的对象；修正直接引用。必要课程、规格、最终交接及独立断言保留，历史实现从Git追溯。
2. **忽略与临时文件清理。** 按精确对象核对本地过程脚本、转换/渲染、重复导出、旧构建/传输、已解决诊断和空目录；必要时处理有充分证据的云端过程副本。实际执行删除，并验证仍需使用的教学/运行/恢复资料保持。

不专门保留只做盘点、不执行已确认删除的特性；不为了删得多建立批量清理脚本、后台任务、全局hook或新归档目录。

## 删除前必须能回答

| 对象 | 用途与消费者证据 | 保留边界 |
|---|---|---|
| 源码、入口、资源 | 静态/动态导入、CLI、包配置、部署和保留版本是否引用；是否有唯一有效替代 | 无引用搜索结果不是单独充分证据；稳定CLI不因文件短而删除 |
| 冗余测试 | 每个独立断言由哪个保留用例覆盖，fixture与网络/权限边界是否保持 | 相似输入或名称不等于重复；不能删除失败用例换通过 |
| 过程报告、导出、构建 | 是否为等价副本、可重建产物；必要结论/有效诊断是否已提取 | 不改写被manifest、catalog、任务或审计引用的原报告 |
| 旧配置、安装、资产 | 当前active/previous、历史run、审批/UNKNOWN、恢复闭包和运行进程的引用 | 旧版本仍可能有消费者；不能仅按日期、M编号或忽略状态删除 |
| 锁、预算、任务文件 | 拥有者是否退出、任务是否结束、是否唯一恢复记录 | 有效锁、未结束累计预算、在途状态与唯一恢复证据保持 |
| 源材料与秘密 | 是否原件、凭据、当前配置或受保护恢复资料 | 不在本M删除范围 |

执行遵循AGENTS：先核对绝对路径及每级重解析点，优先精确单文件删除再删除空目录，不递归越出已核定范围。不自动stash，不覆盖用户修改，不用reset --hard/clean -fd/force push。工具实际拒绝时报告精确动作与实际原因，继续其他可处理对象；不把未知用途伪装成策略拒绝。
