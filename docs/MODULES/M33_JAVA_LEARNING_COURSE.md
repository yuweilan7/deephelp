## 三个顺序特性

1. **上手与主链导读：** 交付课程总入口、章节1–3/8/9的首轮可运行路径及相应核心注释，能离线从一次输入追到事实回复；章节按同一课程导航组织，按需链接待交付章节。
2. **异步与资源时序：** 交付章节4–7及取消/超时/并发/子进程实验；补主链资源拥有者与最终持久化的注释，能说明正常、失败和取消的先后关系。
3. **Agent机制深化：** 完成章节10–14及前述章节交叉链接/练习答案，检索、记忆、审批、评测/发布的代码注释同步完成；总入口不再包含空白/待写章节。

## 每章及注释的标准

每章先给业务问题和学习目标，解释所需前置，再以普通话说明原理；Java类比同时标注边界，不把await写成阻塞Future.get、不把Task写成线程。给最小可执行实验、预期事件/结果、逐步解释、当前生产源码/关键符号、两个以上容易犯的错，以及一项改动/预测练习和答案。命令从仓库根可复制执行，说明是否离线、是否合成、是否会请求模型；正常阅读/默认实验模型0次。

异步章必须包含时序图和任务/资源表：创建者、拥有者、启动点、等待点、取消来源、清理完成点、结果/异常的接收者。用Event/受控屏障固定顺序，用断言证明先后/重叠，不用严格毫秒断言或sleep猜调度。展示取消前、取消请求后、finally完成后的状态；解释shield保护等待的对象、外层取消如何处理，以及运行中线程/进程工作不随await取消强停。

源码注释以中文解释意图和难点：模块职责/调用关系、公开入口输入输出/错误、每个关键await等待什么及交还哪个任务、锁保护哪个不变量、事务何时提交、finally收回哪些资源、异常为何传播。先为关键链路和高级用法加注释，不重复“给变量赋值”等显然语句，也不在源码复制整章教程。过密复杂写法在等价且更清楚时改写；行为变化按对应验收处理，不能借注释顺带改业务策略。

## 可观察的验收

读者通过课程能回答：一条请求在哪暂停；谁阻止重复工具效果；为什么缺槽位工具0次；相同message_id为什么读原receipt；PG、Redis、Milvus、官方saver、Langfuse各保存什么；在哪里看一次模型/工具的输入、结果与原证据。三条主线练习使用优惠未到账、补订单号、无关物流拒识，随后用交错问题、取消和UNKNOWN深化。

所有新增实验在Python3.14.7实际运行、具有关键事件断言，默认禁止网络；安装后的learning入口也能运行。原业务能力不复制、不以fake证明模型质量。文档链接/命令/符号准确，引用M32最终路径；对关键注释进行实际源码走查，不能只报告增加注释行数。每个特性交付必要文档与实验/注释结果，失败/未执行明确列出；不补造“用户已学会”的结论。

教学与注释通常离线验收。如发现并修复实际异步/业务缺陷，单列影响与适用回归/真实证据，不把模型调用作为讲课必需条件。完成全部课程后停止，M35/M36消费同一套教程内容与案例。
