# M46｜可追溯、可控制的跨会话长期记忆

**状态：** `IMPLEMENTED_LIVE_VERIFIED`；2026-10-06，全部三个feature完成，实际内容/安装/恢复范围见[交接](../../handoffs/M46.md)。
**来源：** PDF文件页62–66及75的长短期记忆/持续上下文方向。当前已有同会话持久状态与向量检索；跨会话选择、冲突和遗忘策略是本项目新增设计。
**基线：** M39；复用[M10](M10_MEMORY_LIFECYCLE.md)、[M11](M11_EVENT_CLUSTER.md)、[M12](M12_CASCADE_PIPELINE.md)、[M15](M15_DURABILITY_APPROVAL.md)、[M25](M25_POSTGRES_FACTS.md)、[M36](M36_EXPLAINABLE_WORKBENCH.md)。可独立实施；只有向已存在多Agent提供上下文时再核对M40接口。

## 能力与边界

原`MemoryService`和Milvus查询仍按identity+session限制，具备PG回查/版本与可重建投影。M46在同一已验证主体下，明确选择允许的历史来源，形成带证据的记忆候选；当前会话状态与历史上下文各自保持职责。

先支持已结束问题的可引用摘要/来源、用户明确保留的稳定信息以及相关历史候选。业务订单/金额/券状态仍需查询当前权威事实；历史槽位不自动变成当前confirmed，也不借相似度自动合并其他question。默认原同会话行为保持，跨会话使用有明确开关/范围和可读状态。

记忆候选绑定owner、来源session/question/message、类型、源版本/hash、时间、有效范围、保留状态及证据引用。确定性摘要是派生信息，回查当前合法来源和当前问题后才作为回答末尾参考；不会填槽或送进模型。遗忘/撤回/过期/越权/版本漂移均拒绝，没有M46向量或缓存副本。

开启、限定来源、纠正与遗忘是明确操作，保持服务端身份/CSRF/CAS边界。已实现API/类型及与原同session接口的区别见CONTRACTS；遗忘不删除原账本或审计材料。

## 三个顺序feature

### 1. 跨会话历史候选与来源回查

交付同owner、明确允许的两个会话之间的记忆生成/检索/详情/选择，先采用确定性摘要或受控人工保留信息；摘要需要模型时显式执行，使用原共享预算并记录实际版本/usage。数据持久记录/必要outbox沿用PG事实职责，索引可重建。

至少一条新会话请求能引用已结束历史的合法来源，再以当前槽位/工具事实回答；未开启/无候选/外主体/源版本过期有明确结果。原活动归属与同session缓存不被跨会话查询替换。

同步新增Python的scope/派生摘要/回查说明，在原多轮记忆页展示来源会话、时间、证据、候选/已采用差别；给两会话离线实验及预期结果。直接替代的临时历史拼接路径当项删除，不复制记忆仓储。

### 2. 冲突、有效期与可控遗忘

交付新旧槽位冲突、明确订单不匹配、过期/低可信、上下文长度/候选数上限的选择策略；当前已确认信息优先，历史仅提示/澄清。明确更正保存版本与来源，不last-write-wins抹掉证据；结束问题不能因历史命中变为活动问题。

提供停用/撤回某条记忆、来源范围修改和遗忘操作，停止后不再注入该记忆；投影/缓存失效与延迟outbox重建须识别撤回版本，不能把已遗忘内容再次投回索引。业务账本、审批/UNKNOWN和审计依赖按原保留规则处理，遗忘检索记忆不等于销毁事实记录。

同步中文解释冲突判定、撤回/投影时序与资源清理；页面显示采用/拒绝/过期/已遗忘及具体理由，教程提供旧订单误用与撤回重放反例。当项清除无消费者缓存/候选副本，保持引用资料。

### 3. 生命周期、真实内容与正式交付

验证多会话相关/无关输入、用户明确续接与新话题、历史摘要冲突、纠正/遗忘/进程重启与投影重建的完整路径。真实模型/Embedding仅覆盖必要召回与回答内容；当前业务事实来自原MCP/PG，比较启用/关闭长期记忆的事实正确性与错误引导。

记忆schema、生成/选择策略、Prompt、索引签名与配置纳入原精确发布；新增索引按可恢复方案交付，旧安装/schema兼容或停止边界必须实际证明，不能承诺任意跨schema回退。保留旧同session运行方式，交付新安装及相应恢复入口。

工作台/教程核对正式版本里的跨会话来源、预算、故障/未知/重放解释；多Agent已交付时仅沿受控委托传递已核验上下文，不扩权。清除本轮未引用构建/迁移中间副本，旧运行/审批的恢复闭包不删除。

## 可观察的验收

| 证明目标 | 最小必要证据 |
|---|---|
| 跨会话能力 | 两个独立session实际召回同owner合法历史，带原记录来源/当前版本；关闭时仍是原同session路径 |
| 身份与事实 | 外owner、伪造来源、过期/删除记录、相似但不同订单、旧槽位覆盖confirmed均被拒绝/澄清 |
| 生命周期 | 终态不自动重开；审批不被历史消息批准/恢复；纠正、遗忘、缓存/outbox晚到与重建不复活撤回记忆 |
| 有界/质量 | 候选与上下文上限、取消/未知usage正确；本次必要召回/回答内容真实比较，无提升不宣称记忆提高质量 |
| 学习/恢复 | 浏览历史0模型，候选/采用/拒绝/来源清晰；实际新安装与限定恢复路径有证据，诊断故障不重放业务 |
