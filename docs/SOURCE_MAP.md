# 原文索引与读取边界

原件为用户提供的《客诉场景的自动驾驶 DeepHelp》78 页截图 PDF。它没有可靠文本层，也不是作者源码、完整训练数据或完整 SOP；核对时以 PDF 文件页码和页图为准。

本机可把 PDF 放在 `docs/` 或旧的 `.local/references/`。规划者必须按 [source-manifest](references/source-manifest.json) 的 SHA-256 识别文件；原件受 `.gitignore` 保护，不提交公共仓库。

| 文件页 | 可支持的设计 | 不能据此宣称 |
|---|---|---|
| 1-14 | 原项目介绍、界面与作者效果陈述 | 本复刻达到原项目线上效果 |
| 15-24 | 系统分层、Pipeline、清洗与提取 | 作者所有图完全一致；示意阈值已校准 |
| 25-35 | 意图层级、规则/召回/记忆/兜底 | 可恢复完整意图库或隐含路由 |
| 35-41 | Dense/Sparse、BM25、融合与向量字段 | 裸分可直接混加；融合分是概率 |
| 41-54 | FastText、误判分析与数据回流 | p52 矛盾输出原因已知；回流样本无需审核 |
| 55-61 | 多轮事件聚合、问题归属与 13 段细化 | 模糊补充总属于最近问题 |
| 62-66 | Redis/关系库/向量库与问题生命周期 | 缓存是业务事实源；checkpoint 可替代业务表 |
| 67-69 | SOP、MCP/Skill、受控 ReAct 与输出 | 原文已给出完整审批、幂等和崩溃恢复 |
| 70-71 | 调试、trace 与评测方法 | 原项目 500+ 数据可供本项目直接使用 |
| 72-76 | AI 原生开发与分期建设 | 作者指标成为本项目实测结果 |
| 77-78 | 文章目录截图 | 新增实现细节 |

原文 p19 概述为 12 步，p57 详细图为 13 段；本项目采用 p57。p58 的事件聚合不重新识别主意图，p60 的 600 阶段是统一主意图服务入口。其余原文与工程改造的裁决见 `docs/DECISIONS.md`。
