## 4. S02 JSON语义样例与反例

下列是手写的设计fixture，不是HTTP/Pydantic定义，也不是实际响应。外层`input`/`expected`仅组织验收信息；run_status、计数等是断言，不塞入尚未发布的ResponseEnvelope。标识全部合成，版本未配置不捏造。HTTP映射由M02发布。

### J1：缺订单

```json
{
  "input": {
    "trusted_identity": {"tenant_id": "tenant-demo", "user_id": "user-a"},
    "channel": "test", "session_id": "session-slot", "message_id": "m-slot-1",
    "request_id": "req-slot-1", "raw_text": "我的券不能用", "question_hint": null
  },
  "expected": {
    "response": {
      "request_id": "req-slot-1", "run_id": "r-slot-1", "trace_id": "trace-slot-1",
      "question_id": "q-slot", "outcome": "CLARIFY", "question_status": "WAITING_SLOT",
      "reply": "请补充订单号。", "facts": [], "evidence_refs": [], "error": null,
      "next_action": {"type": "provide_slots", "missing": ["order_id"]}
    },
    "run_status": "SUCCEEDED", "question_version": 1, "tool_calls": 0,
    "next_new_message": {"message_id": "m-slot-2", "run_id": "r-slot-2", "resume": false}
  }
}
```

当前选定fixture只要求order_id；真实SOP的完整槽位由版本化定义提供。缺槽位不是HTTP500，不挂起r-slot-1；同m-slot-1且同payload重投返回r-slot-1结果，即使request_id不同，也不得新增q/run或工具调用。相同message_id而正文hash变化返回IDEMPOTENCY_CONFLICT。

### J2：跨用户case

```json
{
  "input": {
    "trusted_identity": {"tenant_id": "tenant-demo", "user_id": "user-b"},
    "channel": "test", "session_id": "session-denied", "message_id": "m-denied",
    "request_id": "req-denied", "raw_text": "读取这个问题", "question_hint": "q-owned-by-a"
  },
  "expected": {
    "response": {
      "request_id": "req-denied", "run_id": null, "trace_id": "trace-denied",
      "question_id": null, "question_status": null, "outcome": "REJECTED",
      "reply": "无权执行该请求。", "facts": [], "evidence_refs": [],
      "error": {"code": "FORBIDDEN"}, "next_action": {"type": "none"}
    },
    "business_writes": 0, "tool_calls": 0, "separate_security_audit_allowed": true
  }
}
```

拒绝用当前可信身份执行，不相信正文自报tenant/user；响应不暴露对象存在性。null run/question是入口拒绝时不适用，不是伪造一个他人的case再删除。

### J3：外部结果未知

```json
{
  "input": {
    "entry": "authenticated_reconciliation", "request_id": "req-unknown",
    "trusted_identity": {"tenant_id": "tenant-demo", "user_id": "user-a"},
    "run_id": "r-unknown", "question_id": "q-unknown",
    "operation_id": "op-unknown", "operation_status": "UNKNOWN",
    "downstream_query": "still_unknown"
  },
  "expected": {
    "response": {
      "request_id": "req-unknown", "run_id": "r-unknown", "trace_id": "trace-unknown",
      "question_id": "q-unknown", "question_status": "HANDED_OFF", "outcome": "HANDOFF",
      "reply": "操作结果尚未确认，已转入对账处理。", "facts": [], "evidence_refs": [],
      "error": {"code": "OPERATION_UNKNOWN"},
      "next_action": {"type": "reconcile_operation", "operation_id": "op-unknown"}
    },
    "run_status": "FAILED", "operation_status": "UNKNOWN",
    "new_write_tool_calls": 0, "reconciliation_queries_this_attempt": 1,
    "external_effect_count": "unknown", "same_operation_on_recovery": true
  }
}
```

这是一次查询仍未知的停止分支，不声称效果已经发生或成功；保留原run/op以供重新授权后对账。D06主走查则选择“查询证实已成功”的分支，最终效果1。两者不矛盾。

非top1反例：候选`DEMO-COUPON`分类概率0.9、`DEMO-ACTIVITY`分类概率0.1，最终选择后者却没有已发布且通过校验的override_rule_id/证据，700必须拒收；可在剩余预算内修复，无效则MODEL_OUTPUT_INVALID或安全人工路径，工具0。仅附自然语言“我认为更合适”不能使决策有效；cosine/BM25/fusion不得改称统一confidence。
